# Q5 - Bakery Website (Express.js with HTML Pages)

## Aim
Create a three-page Express website for a bakery: `/` (home), `/menu` (cakes and pastries) and `/contact` (phone number and address), with shared CSS served from `public/`.

## How to Run

```bash
cd Q5_Bakery-Express-Website
npm install
npm start
```

Then open `http://localhost:3000` in a browser.
